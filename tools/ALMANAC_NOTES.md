## 一、已确认无误的规则

### 1. 日干支
`干支序 = (JDN + 49) mod 60`，0 = 甲子。
验证：1949-10-01 应为甲子日（JDN 2433191，(2433191+49)%60 = 0）✓；
A=壬辰、B=癸巳、C=乙亥，三者全中 ✓

### 2. 月建（节气定月）
以**节令**换月，不是农历月：
立春→寅月、惊蛰→卯月、清明→辰月、立夏→巳月、芒种→午月、小暑→未月、
立秋→申月、白露→酉月、寒露→戌月、立冬→亥月、大雪→子月、小寒→丑月。
验证：C=2026-01-01 时小寒（1/5）未到，仍属子月 → 戊子月 ✓

### 3. 建除十二神
`idx = (日支 - 月支 + 12) mod 12`，顺序：建除满平定执破危成收开闭
- A：辰(4)−酉(9) = 7 → **危** ✓
- B：巳(5)−酉(9) = 8 → **成** ✓
- C：亥(11)−子(0) = 11 → **闭** ✓

### 4. 黄道黑道十二神（值神）
起青龙口诀：**子午起申、卯酉起寅、寅申起子、巳亥起午、辰戌起辰、丑未起戌**
顺排：青龙 明堂 天刑 朱雀 金匮 天德 白虎 玉堂 天牢 玄武 司命 勾陈
- A：酉月 → 青龙起寅；辰日 = 寅+2 → **天刑**（黑道）✓
- B：酉月 → 青龙起寅；巳日 = 寅+3 → **朱雀**（黑道）✓
- C：子月 → 青龙起申；亥日 = 申+3 → **朱雀**（黑道）✓
黄道六神：青龙、明堂、金匮、天德、玉堂、司命

### 5. 二十八宿值日 ★关键锚点★
`宿索引 = ((JDN + 12) mod 28)`，余 0 取 28；索引 1..28 = 角…轸

推导依据：歌诀「角亢氐房心尾箕」对「四五六日一二三」→ **角恒为星期四、房恒为星期日**。
据此先定 k mod 7，再用真实数据定相位偏移。

- A：JDN 2461299 → (2461299+12) mod 28 = 27 → **翼**（翼火蛇）✓ 实测"翼火蛇"
- B：JDN 2461300 → 余 0 → **轸**（轸水蚓）✓ 实测"轸水蚓"
- C：JDN 2461042 → (2461042+12) mod 28 = 22 → **井**（井木犴）✓ 实测"井木犴"

> 注意：另有「三合局起宿法」（寅午戌起角、巳酉丑起斗、申子辰起奎、亥卯未起井 + 星期顺位）
> 也广为流传，但它与"角恒为星期四"这条铁律**互相矛盾**（会差 7 位）。
> 实测数据只支持本项目的公式，两个非相邻样本（A 与 C 相隔 257 天）都对上了。

## 二、需注明"参考"的部分

以下项目各家通书版本不一致，本项目按主流起例实现，但**不保证与任一商业黄历逐字相同**：

| 项目 | 分歧情况 |
| --- | --- |
| **宜 / 忌** | 由神煞叠加合成，无唯一权威答案。同一日不同通书结果常不同 |
| **福神方位** | 按日干表（本项目实测反推）：甲/戊/己→正北、乙/庚→西南、丙/辛→西北、丁/壬→东南、癸→东北。此表与常见书不同，以实测源为准 |
| **不将、敬安、普护、要安、圣心** 等 | 起例繁琐，按常见规则实现 |
| **宜忌用词** | 各家用词粒度不同（如"嫁娶/结婚/接亲"同义），本项目取通行标准词 |
